# Contributing to Simple Interest Calculator

First off, thank you for taking the time to contribute! 🎉

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome. Whether you are a seasoned developer or just getting started, your input helps make this project better for everyone.

## How to Contribute

### 1. Reporting Bugs
If you find a bug, please create an issue on GitHub describing:
- Your operating system and environment.
- Clear steps to reproduce the issue.
- Expected vs. actual behavior.

### 2. Suggesting Enhancements
Have an idea for a new feature or improvement? Open an issue to discuss your proposal before writing code.

### 3. Pull Requests
- Fork the repository and create your branch from `main`.
- Make your changes or bug fixes.
- Ensure your code follows the project structure.
- Submit a pull request with a clear description of your changes.
